# Real-image benchmark dataset template

Do not commit real plate images unless their privacy and licensing allow it.
Copy this directory outside the repository, place images under `images/`, and
create a private manifest based on `manifest.example.json`.

Run the existing benchmark tool with the external directory. Report exact
match, character accuracy, false positives, unreadable/review rate, latency and
images per minute for Nhanh, Cân bằng and Kỹ. Synthetic benchmark results must
not be presented as production accuracy.
