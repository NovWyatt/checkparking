## 3. Production cleanup

- Queue request/result có giới hạn; task chỉ truyền request ID, đường dẫn ảnh/crop, mode, loại biển và ngưỡng cần thiết.
- Không truyền API key, Telegram token hoặc secret sang công cụ OCR.
- PaddleOCR khởi tạo một lần trong phiên bình thường.
- Mỗi batch chỉ được tự khởi động lại công cụ nhận diện một lần; không có restart loop vô hạn.
- Stop giữ inference đang chạy hoàn tất, bỏ task chưa chạy và giữ kết quả đã xong.
- App close gửi shutdown, chờ có timeout và chỉ terminate như fallback cuối.
- UI dùng thông báo tiếng Việt thân thiện, không hiển thị thuật ngữ kỹ thuật multiprocessing thông thường.
